# 📚 Interview Prep

Interview Prep is a full-stack MERN Stack web application that helps students and job seekers prepare for technical and HR interviews through AI-powered mock interviews.

Users can practice interview questions, receive intelligent feedback on their answers, track their performance, and improve their interview skills with personalized recommendations.

## 🚀 Live Demo

[Try Interview Prep](https://interview-prep-gamma-red.vercel.app/)
